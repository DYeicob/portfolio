# Portfolio · Jacobo Montero Naranjo

Source code of my personal portfolio, live at **https://portfolio-jmn.netlify.app/**

3rd-year Computer Engineering student at ESEI (Universidade de Vigo) and Assistant at GDG Ourense. The site gathers my experience, projects, skills and education.

## 🛠 Technologies

* **HTML5** (semantic markup, Open Graph meta tags)
* **CSS3** (custom properties, Flexbox, Grid, responsive layout, `prefers-reduced-motion`)
* **JavaScript** (ES6+, no dependencies)
* Deployed on **Netlify**

## 🚀 Run locally

```bash
git clone https://github.com/DYeicob/portfolio.git
cd portfolio
# open index.html in your browser, or serve it:
python3 -m http.server 8000
```

## 📂 Structure

* `index.html`: all content (about, experience, projects, skills, education, contact)
* `css/styles.css`: styles
* `js/main.js`: smooth scrolling and footer year
* `img/`: profile and project images (optimised JPG)
